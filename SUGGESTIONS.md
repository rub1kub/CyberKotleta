# Предложения по доработке сервера CyberKotleta Core

## Приоритет 1: Критические улучшения

### 1. Уведомления о level-up в Discord
**Текущее состояние:** Level-up только логируется в консоль.

**Предложение:**
- Добавить ephemeral ответ пользователю при повышении уровня через событие в `cogs/levels.py`
- Или отправлять DM с поздравлением и embed
- Можно добавить роль-награду за достижение определённых уровней (например, уровень 10, 25, 50)

**Файлы для изменения:**
- `cogs/levels.py` - добавить обработчик события level-up
- `db/database.py` - метод `add_experience` уже возвращает `level_up` флаг

### 2. Антиспам для опыта и репутации
**Текущее состояние:** Нет защиты от спама сообщений и злоупотребления репутацией.

**Предложение:**
- Кулдаун для начисления опыта за сообщения: минимум 10 секунд между сообщениями
- Фильтр коротких сообщений: меньше 3 символов не дают опыт
- Кулдаун для репутации: 1 голос в минуту на одного пользователя (уже частично есть через `reputation_votes`, но можно улучшить)

**Файлы для изменения:**
- `cogs/stats_messages.py` - добавить проверку кулдауна и длины сообщения
- `cogs/reputation.py` - улучшить проверку кулдаунов

### 3. Исправление ошибки в stats_voice.py
**Текущее состояние:** В терминале видна ошибка `TypeError: unsupported operand type(s) for -: 'datetime.datetime' and 'str'`

**Статус:** ✅ **ИСПРАВЛЕНО** - добавлен парсинг datetime из строки в `db/database.py`

## Приоритет 2: Важные улучшения

### 4. Автоматические бэкапы БД
**Предложение:**
- Создать скрипт `scripts/backup_database.py` для периодического дампа БД
- Запускать через cron или discord.ext.tasks раз в день
- Сохранять в папку `backups/` с датой в имени файла: `cyberkotleta_YYYY-MM-DD.db`
- Автоочистка старых бэкапов (оставлять последние 30 дней)

**Реализация:**
```python
# scripts/backup_database.py
import shutil
from datetime import datetime
from pathlib import Path

async def backup_database(db_path: str):
    backup_dir = Path("backups")
    backup_dir.mkdir(exist_ok=True)
    
    timestamp = datetime.now().strftime("%Y-%m-%d")
    backup_path = backup_dir / f"cyberkotleta_{timestamp}.db"
    
    shutil.copy2(db_path, backup_path)
    
    # Удалить старые бэкапы (старше 30 дней)
    # ...
```
